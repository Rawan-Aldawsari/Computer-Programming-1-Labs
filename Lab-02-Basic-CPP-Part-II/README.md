
# Lab 02 - Basic C++ Part II

## Overview
This lab covers increment and decrement operators,
relational operators, logical operators, output formatting,
and arithmetic expressions in C++.

## Lab Exercises
- Program 1: Increment and Decrement Operators
- Program 2: Relational Operators
- Program 3: Logical Operators
- Program 4: Output Formatting Using setw()

## Assignment
- Question 1: Arithmetic Expressions
- Question 2: Modulus and Arithmetic Expressions
- Question 3: Valid and Invalid Assignments
- Question 4: Variable Values
- Question 5: Output Statements
- Question 6: Type Casting and Arithmetic
- Question 7: Arithmetic Expressions in C++

C++
