
# Question 1: Input Statements and Variable Values

Given:
- x and y are int variables.
- ch is a char variable.
- Input: 5 28 36

## a. cin >> x >> y >> ch;

x = 5
y = 28
ch = '3'

Explanation:
The character variable reads the first character of 36.

## b. cin >> ch >> x >> y;

ch = '5'
x = 28
y = 36

Explanation:
The character variable reads the first input character,
then the remaining values are assigned to x and y.

## c. cin >> x >> ch >> y;

x = 5
ch = '2'
y = 8

Explanation:
The character variable reads the first character of 28.
The remaining character 8 is then read as an integer.
